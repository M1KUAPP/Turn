## What judges are looking for

The Best Game Award is for a mobile game that feels fun, polished, and
thoughtfully monetized. Judges are looking for strong gameplay, a clear art
direction, and a monetization model that fits the genre instead of fighting it.

Your game does not need to be huge. It should feel coherent, playable, and
convincing as a shipped experience.

## What to include

- A description of the core gameplay loop.
- Notes on the art direction, tone, and what makes the game memorable.
- An explanation of how the monetization model fits the genre and player
  experience.
- A demo video that shows real gameplay on the device the game was built for.
