## Zero to ship beginner quest

Take the personalized beginner quest **Zero to Ship**: four quick questions, one
route from an empty project to your first shipped subscription. Start the quest
at [RevenueCat Start](https://revenuecat.github.io/start/) .

## Get integrated, fast.

RevenueCat builds native SDKs for iOS, Android, and many cross-platform
frameworks, plus the backend infrastructure for easily adding in-app purchases
to your mobile apps. Use these official docs, codelabs, and tools to get
integrated fast and spend your Shipaton time building.

## General docs && codelabs

- [**RevenueCat SDK Docs**](https://www.revenuecat.com/docs/getting-started/quickstart)
  : The official quickstart — install the SDK, add your API key, and make your
  first purchase in minutes.
- [**RevenueCat Codelabs**](https://revenuecat.github.io/) : The home for
  hands-on, step-by-step coding labs that walk you through real RevenueCat
  integrations end to end.
- [**Google Play Integration**](https://revenuecat.github.io/codelabs/google-play.html#1)
  : Connect Google Play Console: create products, link your service account, and
  test purchases on Android.
- [**App Store Integration**](https://revenuecat.github.io/codelabs/app-store/index.html)
  : Set up App Store Connect: configure in-app purchases, subscriptions, and the
  App Store Server connection.

## Troubleshooting

- [**Troubleshooting RevenueCat Integration**](https://revenuecat.github.io/codelabs/troubleshooting/index.html)
  : A focused codelab for diagnosing and fixing the most common SDK integration

- [**General Troubleshooting**](https://www.revenuecat.com/docs/revenuecat-support/general-troubleshooting)
  : The docs troubleshooting hub covering sandbox testing, entitlements, and
  frequent configuration mistakes.

## Pick your stack.

Native and cross-platform SDKs all reach the same RevenueCat backend. Jump
straight to the docs and codelabs for the framework you are shipping with.

## Android

- [**RevenueCat Android Docs**](https://www.revenuecat.com/docs/getting-started/installation/android)
  : Install and configure the native Android SDK in your Kotlin or Java app.
- [**Android In-App Purchases & Paywalls Codelabs**](https://revenuecat.github.io/codelabs/android.html#0)
  : Build Android purchases and native Paywalls step by step in a hands-on lab.

## iOS && Apple

- [**RevenueCat iOS & Apple Docs**](https://www.revenuecat.com/docs/getting-started/installation/ios)
  : Install and configure the SDK across iOS, iPadOS, macOS, and the rest of the
  Apple platforms with Swift.
- [**iOS In-App Purchases & Paywalls Codelabs**](https://revenuecat.github.io/codelabs/ios.html#0)
  : A guided lab for wiring up StoreKit purchases and native Paywalls on iOS.

## React native

- [**RevenueCat React Native Docs**](https://www.revenuecat.com/docs/getting-started/installation/reactnative)
  : Add the SDK to a bare React Native app and share purchase logic across iOS
  and Android.
- [**RevenueCat Expo Docs**](https://www.revenuecat.com/docs/getting-started/installation/expo)
  : Integrate RevenueCat in an Expo project, including config plugin and EAS
  build setup.
- [**React Native In-App Purchases & Paywalls Codelabs**](https://revenuecat.github.io/codelabs/react-native.html#0)
  : Implement cross-platform purchases and Paywalls in React Native through a
  hands-on lab.

## Kotlin multiplatform

- [**RevenueCat Kotlin Multiplatform Docs**](https://www.revenuecat.com/docs/getting-started/installation/kotlin-multiplatform)
  : Set up the KMP SDK to share your purchase and subscription code across
  Android and iOS.
- [**Kotlin Multiplatform Purchases & Paywalls Codelabs**](https://revenuecat.github.io/codelabs/kmp.html#0)
  : A guided KMP lab covering shared purchase logic and Paywalls.

## Flutter

- [**RevenueCat Flutter Docs**](https://www.revenuecat.com/docs/getting-started/installation/flutter)
  : Install and configure the Flutter SDK to manage purchases from a single Dart
  codebase.
- [**Flutter In-App Purchases & Paywalls Codelabs**](https://revenuecat.github.io/codelabs/flutter.html#0)
  : Build Flutter in-app purchases and Paywalls step by step in a hands-on lab.
